"Qaqqaqaqaaq" का क्या मतलब है?

मेरा Github username Kalaallisut [kalaːɬːisʉt] (पश्चिमी Greenlandic) ज़बान में एक लफ़्ज़ है। यह एक polysynthetic ज़बान है, जो कई morphemes जोड़कर लफ़्ज़ बनाती है, जिससे 'sentence-words' बनते हैं जैसे:

qaqqaq -qa -qi -voq
पहाड़ है emph 3.ind
'वहाँ बहुत सारे पहाड़ हैं'
यह कैसे होता है? qaqqaq आख़िरी -q खो देता है -qar- जैसे suffixes से पहले। फिर, -qar- अपना आख़िरी -r- खो देता है suffix -qi- से पहले, जो -voq के साथ मिलकर एक मामूली छोटा रूप -qaaq बनाता है।

यह मेरा Github username क्यों है? यह एक वक़्त पर आसान लगा, और मैं ऐसी जगह से हूं जहाँ बहुत सारे पहाड़ हैं!
